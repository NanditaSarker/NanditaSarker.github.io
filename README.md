# Nandita Sarker: academic website

Plain HTML and CSS. No build step.

## Files
- `index.html` Home
- `research.html` Research
- `publications.html` Publications and presentations
- `contact.html` Contact
- `404.html` Page-not-found page (its links start with `/` on purpose)
- `style.css` All styling. Colors are set at the top of the file.
- `.nojekyll` Empty file that tells GitHub Pages to publish the files as they are.

## Editing
Open any `.html` file and change the text between the tags. Keep the tags themselves unchanged.
To add a publication, copy one `<li>...</li>` line in `publications.html` and edit it.
